# Jiefu Android 9 音频直通修复 v1.0.0

适用于 Jiefu / SN5BBAO / PI.4333，S905X2-BU、Android 9、ARM32 用户空间。

修复 TrueHD 无法选择、无声和画速异常，补齐 DTS-HD MA 直通，并通过 HAL 与 AudioFlinger 两层缓冲修正连续断音。用户已确认 TrueHD、DTS-HD MA 7.1 本次持续播放正常。

- `jiefu-audio-v1.0.0.tar.xz`：六个有效系统文件、SHA256、有效清单及部署说明。
- `SHA256SUMS`：发布压缩包校验和。
- 仓库提供完整补丁源码、精确差异、构建工具、FFmpeg对应源码与验证记录。

所有修改在盒子系统层，没有修改飞牛。必须匹配清单原件SHA，不能通刷其他S905X2固件。Atmos仅代码分析、DTS-ES6.1仅代码/音轨创建验证，未宣称接收端实测通过。

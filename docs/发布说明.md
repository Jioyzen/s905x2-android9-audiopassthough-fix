# Jiefu Android9 音频直通修复 v1.0.1

修复默影视EXO播放DTS-HD5.1时“音频输出失败”：原固件每客户端音频共享堆仅1.5MiB，放不下EXO约4MiB的AudioTrack分配。仅修改/vendor/build.prop原生属性，将上限设为8MiB；HAL、封装库和其余前版产物不变。

用户已确认功放点亮DTS-HD、声音正常。

- jiefu-audio-v1.0.1.tar.xz：七个有效文件、校验和及文档。
- SHA256SUMS：压缩包校验。源码、精确差异和单行配置工具均在仓库。

仅用于匹配Jiefu / SN5BBAO / PI.4333；vendor/build.prop只改目标属性，不能跨固件覆盖其他配置。只读ro属性需正常整机重启生效。Atmos及真实DTS-ES6.1仍未接收端实测，不扩大前版验证结论。
